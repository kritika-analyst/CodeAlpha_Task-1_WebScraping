# Job Listings Web Scraper

A Python web scraping project developed to extract real-time job listings data from Internshala using BeautifulSoup and Pandas.

## Features
- Extracts job titles
- Extracts company names
- Extracts locations
- Extracts salary details
- Extracts required skills
- Extracts posted dates
- Saves data into CSV format

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Output-
The extracted data is stored in:
jobs_data.csv

## Project Goal
This project was created to practice:
- Web Scraping
- HTML Parsing
- Data Extraction
- Dataset Creation using Python
